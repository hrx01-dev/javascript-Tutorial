# JavaScript Tutorial Repository

Welcome to The JavaScript learning repository! This repo contains various levels of exercises and projects built while learning JavaScript.

## 📁 Repository Structure

- **Level 0 to Level 4**: These folders contain different concepts, exercises, and small scripts that track the progression of learning JavaScript fundamentals.
- **Project (ConvoX)**: The capstone project of this repository. A fully functional Currency Converter web application.

---

## 💱 ConvoX - The Currency Converter

Located in the `Project` directory, ConvoX is a simple, intuitive web tool that allows you to calculate live exchange rates from USD to other popular currencies.

### ✨ Features
- **Real-time Rates**: Fetches live currency exchange rates using the [FreeCurrencyAPI](https://freecurrencyapi.com/).
- **Dynamic Flags**: The UI automatically updates country flags when you select a new currency, powered by [FlagsAPI](https://flagsapi.com/).
- **Supported Conversions**: Convert USD to EUR, CAD, JPY, INR, and KRW.

### 🛠️ Tech Stack
- **HTML5** for the layout and structure.
- **CSS3** for styling and visual design.
- **Vanilla JavaScript** for the application logic, DOM manipulation, and asynchronous API calls.

### 🚀 How to Run

Since this is a frontend-only application with no build steps, running it is incredibly easy:
1. Clone this repository to your local machine.
2. Navigate into the `Project` folder.
3. Open `index.html` directly in any web browser.
